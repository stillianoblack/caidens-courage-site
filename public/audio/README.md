# Focus Flame Lab audio

Place these files in this folder for `/focus-flame-lab` optional sound:

- `focus-flame-ambient.mp3` — looped background ambience
- `card-hover-bubble.mp3` — scene card hover / focus
- `card-select-chime.mp3` — scene card select / Begin
- `button-soft-click.mp3` — standard UI buttons (not scene cards)

The game stays silent until the user turns sound on in the lab nav.
