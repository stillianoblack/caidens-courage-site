# B-4 Focus Flight Assets

This prototype currently generates its B-4 placeholder, Focus Flames, obstacles, and rainforest/storm background inside Phaser.

Future final assets can live here before being wired into `PreloadScene`.

- B-4 sprite sheet or Spine export
- Flame sprites and particle textures
- Rainforest parallax layers
- Storm obstacle sprites
- Sound effects for collect, hit, combo, buttons, and mission complete
